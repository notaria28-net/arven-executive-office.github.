# ARVEN Asset Sources

All storefront visual assets are packaged locally in this project.

- `assets/branding/arven-logo.jpg` — ARVEN project logo created for this storefront; optimized below 1 MB.
- `assets/products/` — locally packaged product photography prepared for the demo catalog.
- `assets/editorial/` — locally packaged editorial imagery for hero and promotional sections.

The site does not depend on remote image URLs for normal rendering.
